# Mpgsql package icon

`mpgsql-icon.png` is the shared opossum mascot for the `Mpgsql` and
`Mpgsql.Protocol` NuGet packages. Both projects embed the PNG in the package
root and reference it through `PackageIcon`.

The image was generated with the built-in `imagegen` tool, with a transparent
background. It is a square PNG with an alpha channel and is smaller than the
NuGet icon size limit of 1 MB.

## Generation prompt

```text
Use case: logo-brand. Create a new minimalist raster mascot icon for a PostgreSQL .NET library. Subject: only a playful opossum head, in a compact three-quarter view with its pointed muzzle facing slightly left, big round dark ears, a light gray and off-white face, a small pink nose, bright simple black eyes, and a cheerful slightly toothy smile. Take the spirit of a handmade opossum sticker, simplified into a clean flat logo with bold dark charcoal outlines and very few geometric shapes. No body, no scenery, no text, no letters, no watermark, no badge or background shape. True transparent background with alpha. Square canvas, centered head occupying about 80 percent of the canvas, generous clear margin on all sides, ears and muzzle fully inside the frame. Crisp smooth contours, flat solid fills, no gradients, shadows, texture, hatching or tiny fur detail. Make the head immediately recognizable and readable at 32 by 32 and 128 by 128 pixels. Friendly and a little mischievous; retain the distinctive opossum muzzle and ears rather than turning it into a cat, fox or raccoon. Return one finished PNG icon.
```
